# Clearminder CLI

The `clearminder` CLI connects to your Clearminder server.

The CLI covers the first three [GTD steps](https://gettingthingsdone.com/what-is-gtd/): Capture, Clarify, and Organize.

1. **Capture:** Put a thought in the inbox without deciding what to do with it.
2. **Clarify:** Decide whether the thought needs action and name the next action when it does.
3. **Organize:** Keep the decision on the right list, with a project, context, or date when needed.

`capture` returns the new item's UUID. List commands show tables by default and accept `--json` for scripts.
Run `clearminder clarify` to search inbox items and open the clarification wizard.

Start with the [quickstart](quickstart.md). Then use the task guides for [capturing](capture.md), [clarifying](clarify.md), and [organizing](organize.md). The [command reference](reference.md) lists every command, option, and error.
